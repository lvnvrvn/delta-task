# Тестовое задание: Дашборд с графиками и таблицей

Интерактивное приложение на React для визуализации показателей.

### 🚀 Демо

https://delta-task-tau.vercel.app/

### ✨ Реализованный функционал

- Динамическое обновление графика при клике на строку таблицы.
- Адаптивная верстка (Desktop, Tablet, Mobile 425px) с горизонтальным скроллом для таблицы.
- Автоматический расчет динамики показателей (цветовая индикация и проценты).
- Компонентный подход и чистая архитектура данных.

### 🛠 Стек технологий

- **React** (Hooks, State Management)
- **Vite** (инструмент сборки)
- **Recharts** (библиотека для графиков)
- **CSS Modules** (инкапсуляция стилей)

### 📦 Как запустить проект локально

1. Клонировать репозиторий: `git clone [url]`
2. Установить зависимости: `npm install`
3. Запустить проект: `npm run dev`
